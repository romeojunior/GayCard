Thank you for contributing to LGBT Philippines — Resources.

Please use the issue template to suggest new resources or corrections. If you'd like to submit multiple entries or large updates, open a new pull request with changes to `src/data/resources.json`.

How to suggest a resource

1. Click "New issue" → "Suggest a resource" (use the template). 
2. Fill in the name, region, description, URL, and tags. Provide a contact email if available.
3. If you submit personal data or photos, ensure you have permission to publish them. Submissions may be edited for clarity before merging.

Maintainers will review issues and PRs and may follow up for clarifications.

Quick PR guide

- Fork the repo and create a branch `add-resource/your-name`.
- Edit `src/data/resources.json` and add a new object to the array.
- Open a pull request describing your change.

Thank you for helping build a useful, community-maintained resource.
